# Classificador de RG

Projeto de Inteligência Artificial para classificar imagens de documentos em três categorias:

- RG antigo
- RG novo
- Documento inválido

## Objetivo

Analisar características visuais e palavras presentes nos documentos para treinar e avaliar três modelos de classificação.

## Tecnologias utilizadas

- Python
- Google Colab
- OpenCV
- Pytesseract (OCR)
- Pandas
- Scikit-learn

## Etapas do projeto

1. Preparação das imagens.
2. Extração de características visuais e textuais.
3. Geração do arquivo CSV.
4. Treinamento de três modelos.
5. Avaliação dos resultados.

## Observação

As imagens de documentos e os dados pessoais não devem ser publicados no repositório.
